# 🐾 Spring PetStore Service – API Consumption with Spring Boot

## 🧠 Description

Spring Boot project focused on consuming external REST services using a third-party API related to a Pet Store system.

The main purpose of this project is to practice:

* REST API consumption
* HTTP request handling
* JSON response processing
* Gradle-based project configuration

---

## 🎯 Objective

Demonstrate the integration of external services within a Spring Boot application while using **Gradle** as the build and dependency management tool instead of Maven.

---

## 🚀 Features

* 🌐 Consumption of third-party REST APIs
* 📥 Retrieval and processing of external data
* 🔄 Integration using Spring Boot
* ⚙️ Dependency management with Gradle

---

## 🛠️ Technologies Used

* Java
* Spring Boot
* Gradle
* REST APIs
* JSON Processing

---

## ⚙️ Project Setup

### 1. Clone repository

```bash id="6ot0s4"
git clone https://github.com/david-gpe/spring-petstore-service.git
cd spring-petstore-service
```

---

### 2. Build project

```bash id="o4m5zv"
gradle build
```

or using wrapper:

```bash id="0j4mvp"
./gradlew build
```

---

### 3. Run application

```bash id="tt2br2"
gradle bootRun
```

or:

```bash id="g7h9m2"
./gradlew bootRun
```
